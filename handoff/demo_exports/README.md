# Выгрузки демо-запроса сервиса — «план В» для защиты

Если сервис на защите не поднялся, эти файлы показывают то же, что отдаёт живой сервис. Получены командой
`python scripts/make_demo_exports.py` (через те же эндпоинты, что кнопки «Выгрузка» в интерфейсе):

`POST /api/v1/query` с телом `{"bbox": [39.25, 47.95, 39.50, 48.10], "date_from": "2024-09-15", "date_to": "2024-10-10", "source": "gt" | "pred"}`
→ `GET /api/v1/query/{query_id}/burn_scars | hotspots ?format=geojson | shp` и `…/summary?format=json | csv`.

| Файл (`gt_…` — эталон, `pred_…` — модель) | Что внутри |
|---|---|
| `*_burn_scars.geojson`, `*_burn_scars_shp.zip` | контуры гарей, EPSG:4326; атрибуты: `contour_id`, `chip_id`, `fire_event_id`, `severity_class` (1–3), `severity_label`, `area_ha`, `date_pre`, `date_post`, `source` |
| `*_hotspots.geojson`, `*_hotspots_shp.zip` | термоточки VIIRS (точки): время пролёта UTC, спутник, I4 и I5 в K, день/ночь, покров, уверенность |
| `*_summary.json`, `*_summary.csv` | справка: суммарная площадь гарей в га, площади и доли по трём степеням, число контуров, пожаров и термоточек |

| Слой | Гари, га | слабая / средняя / сильная, га | Контуров | Термоточек (день / ночь) |
|---|---|---|---|---|
| эталон (`gt`) | **1 758.92** | 114.96 / 951.92 / 692.04 | 337 | 98 (84 / 14) |
| модель (`pred`) | **1 751.64** | 112.12 / 941.84 / 697.68 | 328 | 99 (84 / 15) |

Площади посчитаны в UTM 37N/38N (пиксель 20 м = 0.04 га), геометрия выгружается в EPSG:4326. Слой `pred` — предсказания на
обучающих сценах (in-sample): это демонстрация работы сервиса, а не оценка качества модели.

**Как открыть в QGIS:** перетащить `gt_burn_scars_shp.zip` в окно QGIS (zip распаковывать не нужно) или добавить `*.geojson`
через «Слой → Добавить векторный слой». Раскраска по степени: «Свойства → Стиль → Категоризированный» по полю `severity_class`.
Справка `*_summary.csv` открывается в Excel (UTF-8 с BOM).
