## Отчёт — `reports/report.md` (+ экспорт в `reports/report.pdf` через pandoc/markdown-pdf; если нет — docx через python-docx)
Структура строго по ТЗ (раздел «Отчёт», с. 15) и по критериям (по 4 балла за каждый из 5 пунктов). Объём 10–20 страниц, каждое утверждение с числом/таблицей/рисунком.

1. **Постановка и протокол оценки.** Две задачи, формат чипов, метрика (формулы, микро-усреднение), особенности private/public (территория + время) → почему групповая и временная валидация. Наш протокол: `configs/folds_*.csv`, seed, что считаем «улучшением» (прирост на обоих сплитах).
2. **Разбор данных (EDA).** Из `reports/eda.md`: только факты с числами и таблица «наблюдение → решение» (≥12 строк). Дисбаланс, классы степени, покров, облачность/valid, шум SAR, техноген, день/ночь.
3. **Baseline и отправная точка.** Из `reports/baseline_review.md`: что делает выданный baseline (компоненты обоих модулей, пороги), его метрики нашей оценкой, ограничения (фиксированные dNBR-пороги на разнородном покрове, отсутствие фильтрации техногена, облака), гипотезы H1…Hn с ожидаемым эффектом, и далее в разделах 4–5 — статус каждой гипотезы (подтверждена/нет, число).
4. **Модуль AF.** Из `reports/af_module.md`: пайплайн (рисунок), признаки, модель, таблица экспериментов и абляций, как отделяем техноген/блики, ошибки с картинками, время.
5. **Модуль BS.** Из `reports/bs_module.md`: то же + пороги по покрову, SCL-политика, SAR, UNet vs LGBM vs ансамбль, матрица смешения классов, влияние облачности.
6. **Эксперименты и сравнения.** Сводная таблица всех экспериментов из `experiments.md` (единая метрика Score и компоненты, оба сплита, seed, время), выбор финальной конфигурации и почему.
7. **Инженерные и предметные решения.** Явно по пунктам критерия: дисбаланс; облака/тени по SCL; фильтрация техногенных и отражающих объектов; покров и рельеф в степени поражения; радиолокация для верификации контуров; устойчивость к фенологии между датами. Для каждого — где в пайплайне, какой эффект (число), и если не помогло — честно, почему.
8. **Сервис.** Кратко из `reports/service.md` + скриншоты.
9. **Итоговое решение.** Схема, финальные метрики (OOF, temporal, public LB), скорость инференса (CPU/GPU), воспроизводимость (числа двух запусков).
10. **Выводы и развитие.** Что дало основной вклад (ранжировано по приросту), оставшиеся ошибки (малые очаги 1 px, ложные контуры на убранных полях, смешение соседних классов, облака), ограничения (данные, вычисления, применимость: другой регион/сезон), план: дообучение на GEE-данных, временные ряды для техногена, S1-временные ряды, калибровка порогов по регионам и т.д.
11. **Воспроизводимость.** Команды (ссылка на README), версии, seed, Docker, время обучения.
12. **Лицензии и источники.** Copernicus, VIIRS/NASA, WorldCover CC BY 4.0, ERA5, OSM, предобученные веса (imagenet-энкодер: лицензия smp/timm), библиотеки.

Проверь: нет противоречий между числами в отчёте, `experiments.md`, README и слайдами (единая таблица `reports/final_numbers.md` — источник истины). Все рисунки подписаны, оси на русском.
