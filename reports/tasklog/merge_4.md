## Отступления от задания и открытые вопросы

- **Порядок**: аудит H100 выполнен ДО чистой проверки (а не после), чтобы чистая проверка шла на окончательном коде.
- **`Dockerfile.gpu` написан, но не собран из-за нехватки места на машине разработки; проверен CPU-образ.** Две попытки сборки заполнили
  диск C: до 100 %, демон Docker завис; по решению пользователя сборка прекращена, демон не чинился, в WSL/Docker ничего не удалялось.
  Для освобождения места с согласия пользователя очищен кэш pip (14 ГБ). Виртуальный диск Docker (`docker_data.vhdx`, 66 ГБ) остался раздутым.
- **Python**: пины `requirements.txt` не ставятся на 3.10 / 3.11 (numpy 2.5, pandas 3.0). Дополнение (коммит `compat: python 3.10 requirements`, тег переставлен на него, архивы пересобраны): добавлен страховочный `requirements-py310.txt` / `-cpu.txt`; на Python 3.10.21 инференс побайтно равен финалу, pytest — код 0 (`h100_readiness.md`, п. 18); `pyproject.toml` — `>=3.10,<3.13`; Python 3.13 — Docker.
- H100 физически не проверялась; оценка времени ≈ 19–22 с — расчётная.
- Удалённого репозитория нет → `git archive` + отдельный zip с `weights/` (см. README §8). `submissions/*.csv` в git не входят (`.gitignore`) —
  финальный файл лежит в `submissions/submission_v5_final.csv` на машине разработки.
